# PlatformPulse v2 - Airport & Railway Info Board

## New Features Added
- 🧳 **Luggage Carousel Countdowns**: Live baggage retrieval belt status & estimated arrival countdowns for incoming flights.
- 💺 **Seat Availability Indicators**: Real-time percentage progress bars showing remaining open seats for instant bookings.
- ⏱️ **Split-Flap Terminal Board Animation**: Classic airport arrival/departure board typography & responsive layout.
- 🚨 **Emergency Broadcast Bar**: Alert system for gate reassignments and platform delays.
- 👥 **Crowd Density Meter**: Color-coded concourse passenger density tracking.

## Quick Start
Open `index.html` directly in any web browser!
